# Правила пользователя для этого проекта

- Не управлять компьютером через UI, не использовать computer-use.
- Не запускать Minecraft с графическим окном. Пользователь разрешил локальные
  проверки Paper-сервера и клиентов без окна для диагностики (последнее уточнение).
- Не подключаться к удалённому рабочему серверу без отдельного указания.
- Разрешены правки кода/данных, сборка jar и паков, статические проверки без запуска игры.
- Не изменять VPN и сетевые настройки.
- Не объявлять баг исправленным в игре на основании одной компиляции: разделять
  внесённое исправление и подтверждённое пользователем поведение.
