# Плиты и установка блоков — r20

Кастомные плиты используют настоящую физическую плиту: нижняя занимает нижнюю
половину блока, верхняя — верхнюю. Две одинаковые половинки можно объединить
в целую плиту. Одна половинка при добыче даёт один предмет, двойная — два.
Применяются те же правила инструмента и скорости добычи, что и для других
кастомных блоков. Плиты можно ставить в воду, их перемещают поршни.

Обычные ванильные плиты не резервируются и не перекрашиваются. Идентичность
кастомной плиты хранится по координатам в Chunk PDC; оригинальная модель и
трещины отображаются через одну визуальную ItemDisplay-сущность. Модели
нижнего/верхнего/двойного состояния взяты из оригинального мода.

Старые плиты на нотных блоках автоматически заменяются нижними половинками
после загрузки чанка. Старый формат не хранил положение верхней половинки:
его видимая модель всегда была нижней, это положение и сохраняется при миграции.
Мир удалять или пересоздавать не нужно.

На r19 воспроизведены два установленных блока и расход двух предметов при
быстром повторе сетевых команд. Сервер видит команды использования, а не
физическое нажатие мыши. В r20 интервал для кастомных блоков по умолчанию
соответствует обычному удержанию ПКМ: 4 тика, то есть 200 мс при 20 TPS.
Он общий для обеих рук и защищает также старые предметы с ванильной основой.

Настройка `plugins/Aether/config.yml`:

```yaml
blocks:
  placement-interval-ticks: 4
```

Минимум — 1 тик. Для быстрого строительства можно выбрать 1; защита тогда
объединяет только команды, пришедшие в один серверный тик. Ванильные блоки
этим параметром не ограничиваются. После изменения конфигурации выполните
`/aether reload` или полный перезапуск.

Для r20 замените JAR и ресурспак одновременно, затем выполните полный
stop/start и переподключитесь. Проверки сервера не заменяют визуальную
проверку в клиенте игрока.
