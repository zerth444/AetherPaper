# Происхождение материалов

Оригинальный мод: **The Aether**, The Aether Team.
Репозиторий: https://github.com/The-Aether-Team/The-Aether
Ветка исходного снимка: `1.21.1-develop`, версия мода 1.5.10 для Minecraft 1.21.1.
Базовый коммит: `e07d30e16fbd0f09cc067b39594035e395dcf996`.

`vendor/the-aether-source.zip` содержит рабочий снимок исходных материалов,
используемый конвертерами этого порта. Это обычный архив с исходниками и ресурсами,
без `.git`, кэшей и данных сервера. Точный SHA-256 записан в `vendor/upstream.json`.
Архив не требует загрузки исходников из чужого репозитория при сборке.

Лицензии оригинала сохранены без изменений:

- `vendor/LICENSE-CODE.txt` — GNU LGPL v3.
- `vendor/LICENSE-ASSETS.txt` — All Rights Reserved.

Код адаптации находится в `plugin/`, преобразования и перевод — в `tools/`.
Авторство оригинальных исходников, графики, музыки и прочих ресурсов не меняется.
Порт не является официальным продуктом The Aether Team.
Открытый доступ к этому репозиторию не предоставляет дополнительных прав на
использование и распространение оригинальных ассетов; их лицензия сохранена
без изменений.

Paper и Minecraft не включены в Git. `tools/paper-build.json` фиксирует официальный
URL и хеш Paper build 82; подготовщик сервера проверяет скачанный JAR по этому хешу.
Клиент Minecraft предоставляет сам разработчик из своей установки.
