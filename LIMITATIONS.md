## L-001 — Нельзя регистрировать новые типы блоков
- **Невозможно:** новый `BlockType` (как в моде).
- **Причина:** серверный плагин без модов не расширяет ванильный реестр блоков.
- **Аналог:** состояния ванильных блоков (note_block/mushroom) + переопределение `blockstates`
  в ресурспаке; для спец-рендера — невидимый носитель + display-сущности.
- **Влияние:** блоки ведут себя как настоящие (постановка/ломание/поршни/вода/взрывы), но
  занимают состояния ванильных блоков; возможен конфликт с ванильными note_block в мире Aether.

## L-002 — Нельзя регистрировать новые типы сущностей
- **Невозможно:** новый `EntityType` (мобы, снаряды).
- **Причина:** ванильный реестр сущностей не расширяется плагином.
- **Аналог:** ванильная сущность-носитель + кастомный ИИ + display-сущности для визуала.
- **Влияние:** хитбокс, звуки, ИИ настраиваются вручную; сложные анимации приближённые.

## L-003 — Нельзя регистрировать новые типы частиц
- **Невозможно:** новые `ParticleType` (aether_portal, frozen, crystal_leaves и т.д.).
- **Причина:** API не позволяет.
- **Аналог:** ближайшие ванильные частицы (`END_ROD`, `SNOWFLAKE`, `SPORE_BLOSSOM_AIR`, `CRIT`,
  `ENCHANT`) + display-сущности для устойчивого визуала кристаллов/портала.
- **Влияние:** визуал частиц близкий, но не пиксель-в-пиксель.

## L-004 — Нельзя добавить клиентские шейдеры/эффекты мода
- **Невозможно:** шейдеры Aether (цветное небо и т.п.) напрямую.
- **Причина:** клиентские шейдеры мода не применяются через ресурспак так же.
- **Аналог:** настройка `biome` эффектов (sky/fog color) в датапаке; display-слои.
- **Влияние:** атмосфера измерений приближена средствами ванильных биомных эффектов.

## L-005 — Кастомные GUI-контейнеры мода
- **Невозможно:** точный клиентский рендер GUI мода (altar, freezer, incubator, accessories, book).
- **Причина:** клиентская часть мода недоступна.
- **Аналог:** Bukkit-инвентари с кастомными заголовками + текстуры фона (если применимо) и
  `item_model` иконок; функциональность 1:1, пиксельный вид фона отличается.
- **Влияние:** функциональность сохраняется; фон может отличаться.

## L-006 — Аксессуары (Curios)
- **Невозможно:** прямая интеграция с Curios (это мод).
- **Причина:** нет мода на сервере.
- **Аналог:** собственные слоты аксессуаров в GUI плагина + применение эффектов по тику.
- **Влияние:** логика сохранена, способ экипировки отличается.

## L-007 — Точные клиентские анимации мобов
- **Невозможно:** идентичная клиентская анимация (Java-классы *Model/*Renderer).
- **Причина:** анимации в моде выполняются на клиенте.
- **Аналог:** display-сущности + планировщик анимаций на сервере (интерполяция поз).
- **Влияние:** анимации приближены; при высокой нагрузке может быть реже в далёких чанках.

## L-008 — Формат данных 1.21.1 → 26.2
- **Невозможно:** загрузить JSON мода без изменений.
- **Причина:** изменился `pack_format` и схемы (рецепты, достижения, worldgen, компоненты).
- **Аналог:** автоматическая миграция скриптом `tools/port_data.py` + ручная вычитка.
- **Влияние:** возможны точечные расхождения, покрываемые тестами целостности.

## L-010 — Кастомные Java-типы в worldgen/рецептах/луте (подтверждено)
- **Невозможно:** загрузить данные мода, использующие кастомные Java-типы: структуры
  (`aether:bronze_dungeon`, `aether:gold_dungeon`, `aether:large_aercloud`), фичи
  (`aether:aercloud`, `aether:crystal_island`, `aether:shelf`, `aether:lake`), плэйсеры
  (`aether:golden_oak_*`, `aether:crystal_*`), процессоры, loot-функции/условия/модификаторы,
  типы рецептов (`aether:freezing` и др.), кастомные spawn-категории, кастомные сущности в спавне.
- **Причина:** ванильный реестр типов не расширяется плагином; `.json` с такими `type` не грузятся.
- **Аналог:** соответствующая логика переносится в код плагина (генератор чанков/структур,
  GUI-станции со слушателями крафта, ручные таблицы лута). Данные сохранены в `aether-mod/`
  как источник.
- **Влияние:** контент реализуем 1:1 по поведению, но не копированием JSON. Это основная
  причина, почему порт нельзя завершить «копированием файлов».

## L-011 — Носитель note_block и составные формы
- **Невозможно:** одним состоянием `note_block` выразить multipart-блоки (лестницы, плиты,
  стены, двери, панели, заборы: у них разная геометрия по направлениям).
- **Причина:** `blockstates` носителя — единый `variants`/`multipart` на блок.
- **Аналог:** полные кубы (камень, земля, руды, листва, облака) мапятся 1:1. Составные блоки
  отображаются базовой моделью (приближённо); при необходимости — `BlockDisplay`/`ItemDisplay`
  для точной геометрии.
- **Влияние:** полные кубы точны; формы лестниц/плит на данном этапе приближены и требуют
  отдельной проработки.

## L-012 — Установка измерения требует перезапуска
- **Невозможно:** сделать измерение доступным в том же запуске, в котором впервые установлен датапак.
- **Причина:** `Bukkit.reloadData()` не перерегистрирует новые измерения (проверено).
- **Аналог:** первый запуск только устанавливает `world/datapacks/aether.zip`; измерение
  доступно после перезапуска (стандартное поведение датапаков). Плагин пишет об этом в лог и
  не создаёт overworld-заглушку.
- **Влияние:** требуется один перезапуск после первого запуска.

## L-014 — Нотные блоки и их инструмент
- **Невозможно:** одновременно использовать состояния note_block как носители и сохранять
  ванильную механику смены инструмента от блока снизу.
- **Причина:** `updateShape` пересчитывает инструмент (см. DECISIONS D-014).
- **Аналог:** обновления нотных блоков отключены на сервере; музыкальные постройки из
  нотных блоков играют только арфой.
- **Влияние:** ограничение касается только музыкального использования note_block.

- **Влияние:** пункт ТЗ «торговцы» не применим к оригинальному моду.

## L-016 — Поведенческие приближения мобов и предметов
- Звуки мобов — ванильные от носителей (кастомные останутся после display-моделей).
- Скорость копания занита, дальность валькирии — клиентские механики.
- Многопрыжковость моа по типам заменена планированием + усиленным прыжком в седле.
- Характеристики брони (прочность) — базовые от тира носителя; защита/зачаруемость близки.
- Яйца моа дают взрослую особь (возраст не поддерживается носителем).
- Облачные миньоны следуют базовой логике носителя.
- Переключатель плаща-невидимки — через приседание (нет клиентской клавиши).
- Тримы брони Aether (zanite/gravitite/amber) недоступны: их ингредиенты — кастомные
  предметы, реестр не расширяется.
- Jukebox-песни играют полностью; остановка — извлечением диска или сносом блока.

## L-018 — Трение и оставшиеся звуки носителей
- Quicksoil, quicksoil glass и pane ускоряют игрока серверным импульсом по движению
  раз в тик; dirt path больше не ускоряет. Это приближение клиентского трения мода.
- Пакетная проверка импульса внутри одного блока пройдена; инерция при отпускании
  клавиш, лодки и поведение при большой задержке ещё требуют проверки.

  шаги, удары при копании и приземление носителя всё ещё могут звучать как дерево.
- Отмена ванильного ломания по-прежнему требует отдельной реализации расхода прочности;
  обработка взрывов и точная геометрия составных блоков остаются открытыми.

## L-009 — Портал: свечение и текстуры
- **Невозможно:** полностью идентичный клиентский рендер портала.
- **Причина:** кастомный рендер блока недоступен.
- **Аналог:** невидимый блок-носитель + display-плоскости с текстурой портала + боевые частицы.
- **Влияние:** портал выглядит как в моде; проходимость сохраняется.
