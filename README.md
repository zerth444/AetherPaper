# AetherPaper

Серверный порт The Aether для **Paper 26.2**, Java **25**. Игрокам нужен обычный
Minecraft **26.2** и ресурспак; устанавливать клиентский мод не требуется.
Текущая готовая сборка — **2026.11.08-r20**, проверенный сервер — **Paper build 82**.
Порт находится в разработке: это ещё не полная копия оригинального мода.

## Быстрый запуск

Для игры пересобирать проект не нужно. Скачайте репозиторий целиком, включая `dist/`.
Нужны Java 25 в PATH (`java -version`) и Python 3.10+ только для подготовки папки.

```sh
python tools/setup_server.py --public-host 127.0.0.1
```

Команда создаст `play-server/`, скачает точный Paper 26.2 build 82 с официального
сервера и проверит SHA-256, установит плагин, ресурспак и конфиг. Сервер автоматически
не запускается. Прочитайте [Minecraft EULA](https://aka.ms/MinecraftEULA), затем
установите `eula=true` в `play-server/eula.txt`. Ключ `--accept-eula` позволяет
явно принять её при подготовке.

1. Запустите `play-server/start.bat` (Windows) или `sh play-server/start.sh` (Linux/macOS).
2. Дождитесь запуска сервера, в консоли выполните `stop`, затем запустите его снова.
   Первый запуск устанавливает встроенный датапак; второй загружает измерение Эфира.
3. Подключитесь клиентом 26.2 к `localhost:25565` и примите ресурспак.

Для игры с другими людьми вместо `127.0.0.1` задайте имя/IP, доступное игрокам.
Игрокам должны быть доступны TCP **25565** (игра) и **8127** (раздача ресурспака).
Управление портами зависит от вашего хостинга; скрипт не меняет сетевые настройки.
Можно вместо встроенной раздачи настроить прямую ссылку на ZIP в `resource-pack.url`
и `self-host: false`. Локальный адрес `127.0.0.1` подходит только для игры на том же компьютере.

## Установка на существующий сервер

Остановите сервер и сохраните резервную копию мира и `plugins/Aether/`.

| Файл из репозитория | Куда положить |
|---|---|
| `dist/Aether-1.0.0.jar` | `plugins/Aether-1.0.0.jar` |
| `dist/aether-resourcepack.zip` | `plugins/Aether/resourcepack.zip` |

`dist/aether-datapack.zip` — отдельная копия встроенного датапака для проверки.
Вручную добавлять вторую копию датапака в мир не нужно: плагин устанавливает и
обновляет его сам. После первой установки нужны два запуска, после обновления —
полный stop/start и переподключение игроков. `/reload` для обновления не используйте.
Хеши готовых файлов находятся в `dist/SHA256SUMS`, сведения о сборке — в `dist/release.json`.

Конфиг по умолчанию: `plugin/src/main/resources/config.yml`; рабочая копия создаётся
в `plugins/Aether/config.yml`. Для друзей настройте `resource-pack.public-host`
или внешний URL. Плагин настраивает `block-updates.disable-noteblock-updates: true`
в Paper для сохранения состояний кастомных блоков.

## Как попасть в Эфир

Постройте вертикальную рамку **4×5 из светокамня**, как рамку портала в Нижний мир,
и вылейте воду внутрь. Войдите в портал. Обратный портал создаётся автоматически.
Для проверки оператор может выполнить `/aether build-portal` или `/aether tpaether`.
Первого оператора назначают из консоли сервера: `op ИмяИгрока`.

- `/aether info` — версия сборки, измерение и URL ресурспака.
- `/aether give <id> [количество]`, `/aether list` — контент и выдача для проверки.
- `/aether accessories` — меню аксессуаров.
- `/aetherlore` или ПКМ Книгой Эфира — интерактивный справочник.
- `/aether tpover` — вернуться в обычный мир.

Административные команды `/aether` требуют права `aether.command` (по умолчанию OP).
Выдача предмета командой не означает, что он доступен в выживании.

## Что сейчас доступно

В r20 кастомные плиты получили настоящую половинную коллизию, верхнее положение
и объединение в целую плиту. Обычные ванильные плиты не переопределяются.
Повторные команды установки ограничены обычным интервалом удержания ПКМ.
Для обновления нужны **JAR и ресурспак вместе**. [Подробности плит и установки](docs/BLOCKS.md).

В r19 исправлены рабочие меню алтаря, морозильника и инкубатора: обработка
начинается в открытом окне, видны шкалы топлива и прогресса. Верхний слот —
предмет, нижний — топливо, справа — результат (у инкубатора птенец появляется
над блоком). [Топливо, примеры и ограничения станций](docs/STATIONS.md).

Острова и портал, местные ресурсы и руды, деревья и саженцы, инструменты, крафт,
плавка, алтарь/холодильник, мобы и книга. В книге **144 доступные статьи** с русским
переводом. Недоступные награды и другой контент без источников скрыты.
Природные подземелья отключены по умолчанию (`dungeons.enabled: false`).
Полное соответствие оригинальному моду, все боссы и все визуальные детали
не заявляются. Известные ограничения собраны в [LIMITATIONS.md](LIMITATIONS.md).

На Paper build 82 выполнены 319 проверок книги, 20 проверок трещин/динамической
скорости, 274 проверки добычи и 173 проверки прогрессии/рецептов на соответствующих
сборках r16–r18. Отчёты — в [docs/verification](docs/verification).
Дополнительно для r19 пройдены 172 проверки станций, включая полные циклы,
все варианты рецептов обработки/ремонта и настоящий stop/start с сохранением.
Для r20 — 122 проверки установки, форм плит, добычи, поршней, трещин и перезапуска.
Это проверки сервера и протокола без графического клиента; визуальные изменения
требуют проверки игроком.

## Разработка и сборка

[Инструкция сборки](docs/BUILD.md) содержит требования, команды и восстановление
исходных материалов из `vendor/the-aether-source.zip`. Скрипты не зависят от имени
пользователя Windows или временных каталогов прежнего компьютера.

```text
plugin/       Java-плагин, встроенные данные, Gradle Wrapper
tools/        конвертеры, проверки, подготовка сервера
vendor/       снимок исходников/ассетов оригинального мода и его лицензии
dist/         готовые JAR, ресурспак, датапак, контрольные суммы
docs/         сборка, происхождение материалов, отчёты проверок
```
